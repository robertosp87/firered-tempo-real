Escolha o seu FireRed

Este site não tem o jogo. Escolha o arquivo do Pokémon FireRed (EUA, versão 1.0) que você tem. O patch é aplicado no seu navegador e nada é enviado para a internet.

O progresso fica salvo neste navegador: depois de salvar no menu do jogo, espere aparecer "Progresso guardado" antes de fechar. Para levar o save para outro aparelho, use Baixar save aqui e Carregar save lá (o arquivo .state do emulador não serve para isso).
